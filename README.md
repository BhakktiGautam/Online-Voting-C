# 🗳️ Online Voting System (C)

A simple **console-based Online Voting System written in C**.
This project demonstrates the use of **structures, arrays, loops, and functions** to simulate an election process.

The system allows users to **register candidates, register voters, cast votes, calculate results, and display voting statistics**.

---

# 🚀 Features

* Add candidates to the election
* Register voters
* Cast votes securely
* Prevent double voting
* Display candidate details
* Calculate election results
* Determine the winning candidate
* Show voting statistics and turnout percentage

---

# 🛠️ Technologies Used

* C Programming Language
* Structures
* Arrays
* Functions
* String handling (`string.h`)
* Console-based interface
